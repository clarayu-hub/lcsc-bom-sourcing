# 示例输入

三种输入格式任选，直接复制就能跑。

字段必要性：

| 字段 | 必要性 | 说明 |
|---|---|---|
| **硬件参数** | **必选** | 需求本体，缺了会先问你 |
| 物料编号 | 可选 | 给了用作 sheet 名；没给会自动命名并标注「由本技能生成」 |
| 品牌 | 可选 | 选型偏好；给了就优先在该品牌内挑候选，跨品牌会标注 |

示例中的物料编号（`DEMO-*`）是虚构占位符——实际使用时换成你自己的内部料号，或者干脆不给。

## ① 多物料 BOM（表格形式）

```
按这个 BOM 查立创库存和价格：

物料编号            硬件参数                              数量
DEMO-R-0603-10K     0603 10kΩ ±1% 100mW                  200
DEMO-C-0603-100N    0603 100nF X7R 50V ±10%              150
DEMO-L-3012-10U     10µH ±20% ≥920mA SMD 3×3             50
DEMO-D-0603-20R     20Ω@100MHz ±25% 0603 2A（磁珠）       100

采购量按最小包装整盘算，现货优先、单价最优。
替代料只要同封装同参数的。
```

## ② 带品牌偏好

```
查这几个料，优先风华和厚声的：

0603 120Ω ±1% 100mW
0603 10kΩ ±1% 100mW
```

品牌只是偏好——如果这两个品牌没有满足参数且有现货的，会补其他品牌并标注出来。

## ③ 单个料号（最快）

给 C 编码可以省掉搜索定位那一步：

```
查一下 C25804 的立创现货和阶梯价，再给 4 个同规格替代
```

> 只给型号或 C 编码时，会先问一句是「按这个型号采购」还是「按它的规格另找替代」——型号不是需求描述，方向问清了再跑。

## 参数越全越准

| 器件 | 建议给全的参数 |
|---|---|
| 电阻 | 阻值、精度、额定功率、封装、温度系数 |
| 电容 | 容值、精度、耐压、介质（X7R/C0G）、封装 |
| 电感 | 感值、精度、额定电流、饱和电流、尺寸、是否屏蔽 |
| 磁珠 | 阻抗@频率、精度、额定电流、封装 |
| 二极管/MOS | 耐压、电流、导通压降/导通电阻、封装 |

缺必填项（如电阻没给阻值、没给封装）会先问再跑；非必填项缺失会如实落入「信息不足」。
