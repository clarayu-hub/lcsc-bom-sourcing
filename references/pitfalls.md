# 已知坑

这些都是实际跑 BOM 时踩到并验证过的，按出现频率排序。

## 型号命名不能推断参数

不要用型号里的数字推断 100MHz 阻抗。实测某厂磁珠系列（如 TDK MAF 系列）型号中的数字是 **900MHz 阻抗编码**——型号含 "121" 的料号在 900MHz 为 120Ω，而 100MHz 实为 20Ω。

凡涉及频率相关参数（阻抗@频率、感值编码等），**一律查参数区或原厂 datasheet，不靠命名规则猜**。

## 搜索引擎快照可能是过期缓存

搜索返回的页面快照中，库存与起订量会与现页严重不符（实测同一料号快照显示分仓数千，现页 `stockNumber` 仅两位数，起订量也对不上）。**库存一律以详情页实抓为准**，快照只能当线索。

## 二手对照表不可信

第三方文章里的「C 编码 ↔ 链接」对应关系经常是错的——实测某文章写的对应关系，实抓详情页是另一个 C 编码。**必须以详情页实抓的 C 编码为准。**

## 搜索页会混入非目标规格

搜索结果里常混入同系列的「爆款 / 立推」商品。实测搜低频小阻抗磁珠会混出 120Ω/220Ω/600Ω 关联品，其中不少现货充足、单价更低，但规格不符。

**必须先按硬参数（阻抗/电流/封装/容值）过滤，再挑详查对象。**

## 停产 / 预售 / 订货

详情页标题带「停产」标记的料号**直接剔除**（页面无价格无库存区）。标注预售 / 订货的商品通常现货为 0，同样按缺货处理。

## 冷门规格可能只有 1 款在售

某些规格组合（小封装 + 大电流 + 低频阻抗，或高阻值 + 超小封装）全站在售有货的可能只有 1 款。如实列 1 款并标注单一供应商风险，**不要放宽参数凑数**。

## 阶梯价有两列

详情页同时给出「梯度折扣价」和「原价」，报价时必须说明用哪一列。

## 额定电流与饱和电流

电感类要区分额定电流与饱和电流；两者数值相等时，峰值电流或高温场景需提示复核余量。

这类**余量不足应判「风险」而不是「符合」**——余量只有个位数百分比时，持续工作接近满载存在发热风险。

## 参数缺失不要猜

截图或文字描述没给的参数（温度系数、额定电压、容差），一律写「信息不足」并列入待确认项。**把「能用」说成「符合」是这类工具最危险的错误。**
