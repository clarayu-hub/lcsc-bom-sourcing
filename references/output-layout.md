# 输出工作簿版式规范

## 工作簿结构

| Sheet | 内容 |
|---|---|
| 第 1 张：`汇总` | 结论层——每个物料一行，填其推荐首选，不切 sheet 就能看全貌 |
| 第 2..N 张 | 每个物料一张，**sheet 名 = 物料编号**（使用者提供，或本技能自动生成） |

## 汇总页（默认九列模板）

```
型号 | 封装 | 「参数 / 规格」 | 单套用量 | 品牌 | 分类 | 商品编号 | 物料号 | 风险评估
```

- 第 1–2 行：标题 + 数据来源与抓取时间
- 第 4 行表头，第 5 行起数据
- `商品编号` 填立创 C 编码；`物料号` 填使用者提供的内部物料编号（**未提供时填自动生成的名称，并标注「由本技能生成」**）
- `单套用量` 使用者未提供时填「待确认」
- `风险评估` 三档口径：
  - **【高】** 单一供应商 / 现货不足 / 规格待确认
  - **【中】** 余量不足或交期长
  - **【低】** 参数符合且有多供应商备份
  - 前缀之后**必须写具体原因**，不只给标签
- 风险物料整行浅黄底
- 表格下方设「说明」行，写口径定义与待确认项
- 冻结窗格设在数据行上方，表头开启筛选

## 物料 sheet 布局：候选为列，属性为行

```
第 1 行  物料编号：DEMO-R-0603-10K          抓取时间：YYYY-MM-DD HH:MM
第 2 行  硬件参数：0603 10kΩ ±1% 100mW     品牌偏好：不限
第 3 行  （空行）
第 4 行  属性 | ★ 候选1 | 候选2 | 候选3 | 候选4 | 候选5
第 5 行起 属性逐行往下
```

物料编号缺省时第 1 行填自动生成的名称，并注明「（由本技能生成）」；品牌偏好填使用者指定值，未指定填「不限」。

**为什么候选横着排**：比某个参数时横着扫一行就能看完 5 个候选，不用左右滚动。

属性行顺序：

| 属性 |
|---|
| 型号 (MPN) |
| 制造商 |
| 立创 C 编码 |
| 现货库存 |
| 阶梯价（全档） |
| 需求量档单价 |
| 整盘档单价 |
| 整盘金额 |
| 封装 |
| 关键参数 |
| 匹配结论 |
| 替代型号 |
| 商品链接 |
| 数据手册 |
| 备注 |

格式规则：

- **列序即排序结果**，第 1 列标 `★ 推荐首选`
- `匹配结论` 行按值着色：符合 / 风险 / 信息不足 三色区分
- 参数来自国际站补充时，在该单元格标注来源（如「温度范围（国际站）」）
- 候选不足 5 个时，**空列不补假数据**，在 `备注` 行注明「同类可选料号稀少，单一供应商风险」
- 某物料全部候选缺货 → **不建该 sheet**，只在汇总页列行并注明原因

## sheet 名硬限制

- 上限 **31 字符**，禁止 `\ / ? * [ ] :`
- 非法字符替换为 `-`，超长截断，并在汇总页备注原始编号
- **使用者未提供物料编号** → 自动命名 `<两位序号>_<规格摘要>`（如 `01_0603_10K`），并在汇总页标注「由本技能生成」
- 汇总页固定叫 `汇总`；若某物料编号恰好叫 `汇总`，该物料 sheet 改名 `<物料编号>-1`
- 编号重名 → **先问使用者**，不静默处理

## 生成 Excel 的技术注意

- **静态快照表直接写计算后的数值，不要写公式**（如 整盘金额 = 盘量 × 单价，算好后写入）。部分预览环境的公式引擎缺失，会显示空白——对快照表反而更稳。
- Windows 环境下终端输出可能不可见：把校验结果写入文件再读回确认。
- 物料编号多于 15 个时工作簿会显著变大，建议分批出。
